# Development roadmap

| Phase | Scope and completion evidence |
| --- | --- |
| 0 | Inventory assets and tools, verify licences and document risks, costs and future accounts. Record verification and create a checkpoint. |
| 1 | Responsive React/TypeScript/Vite shell using approved SG branding, desktop sidebar, mobile tabs, accessible controls and clear empty states. Verify build and responsive navigation. |
| 2 | Choose permitted providers and build server-side metadata and availability adapters. Verify attribution, regional offers, timestamp and link handling. |
| 3 | Implement Supabase accounts, persistence, access policies and basic guest/onboarding flows. Verify account isolation and recovery. |
| 4 | Implement Movie DNA, feedback and weekly recommendations. Verify eligibility, quotas, history, replacement and prediction tracking. |
| 5 | Build Roll the Dice, Spin to Watch and initial discovery. Verify filters, exhausted pools, rotation, fair wheel and reduced motion. |
| 6 | Add saved lists, watch history, ratings and reviews. Verify persistence, permissions and review lifecycle. |
| 7 | Add profiles, community, reporting, XP, achievements and leaderboards. Verify restrictions and repeat-action safeguards. |
| 8 | Build standalone avatar lab. Check glTF/GLB loading, textures, rigs, meshes, materials, animation and performance. |
| 9 | Integrate the avatar editor and founder mascot, including static fallbacks and optional onboarding. Verify configuration persistence. |
| 10 | Add advanced search, supported alerts, group recommendations and statistics. Verify consent, data coverage and calculations. |
| 11 | Prepare configurable premium entitlements and protected administration. Keep billing, adverts and paywalls disabled for the prototype. |
| 12 | Run private beta, access-control review, security and accessibility checks, and browser/device testing. |
| 13 | Confirm commercial data rights, privacy obligations, costs and future payments and advertising arrangements. |
| 14 | Launch approved hosting and installable PWA. Verify deployment, installation and operational readiness. |
| 15 | Evaluate native iOS and Android releases with shared APIs and domain logic. |

Phase 1 is awaiting owner approval. Phase 0 findings are in [PROGRESS.md](PROGRESS.md).
